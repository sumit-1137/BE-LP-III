========================================================
STEP 12: COMMON ERRORS AND SOLUTIONS
========================================================

ERROR 1: FILE NOT FOUND

Reason:
You are in the wrong directory or the file path is incorrect.

Solution:

   cd "C:\LP III"

Then compile using:

   javac -d bin src\DAA\Fibonacci.java


ERROR 2: COULD NOT FIND OR LOAD MAIN CLASS

Reason:
Wrong package name or class name, or incorrect classpath.

Solution:

1. Check package name:

   package DAA;

2. Check public class name.
3. Compile again.
4. Run using:

   java -cp bin DAA.Fibonacci


ERROR 3: JAVA COMPILER NOT FOUND

Reason:
JDK is not installed or PATH is not configured.

Solution:
Check JDK installation and PATH configuration.

Run:

   javac -version


ERROR 4: CLASS NAME DOES NOT MATCH FILE NAME

Example:

File name: Fibonacci.java
Class name: Fibonacci

Both names must match exactly.


ERROR 5: CHANGES NOT REFLECTED

Reason:
You modified the program but did not compile it again.

Solution:

   javac -d bin src\DAA\Fibonacci.java
   java -cp bin DAA.Fibonacci
